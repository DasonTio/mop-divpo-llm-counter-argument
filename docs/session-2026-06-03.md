# Session Notes — 2026-06-03

## What was built

### Demo server (`scripts/demo_server.py` + `scripts/demo.html`)
Interactive web UI for evaluating all 6 methods side-by-side.

**Run:**
```bash
source .venv/bin/activate
PYTHONPATH=src python scripts/demo_server.py  # → http://127.0.0.1:5001
```

**Features:**
- Sidebar: 6 method cards with eval metrics, best-in-class highlighted green
- 10 example prompts (from evaluation set, including CMV-style)
- Prompt input → `Generate` → 2×2 persona card grid (color-coded per persona)
- Skeleton loading state, elapsed time display
- One generator cached in memory; reloads on method switch

**Routes:**
- `GET /` → `demo.html`
- `GET /api/config` → methods, examples, best_metrics, persona_info
- `POST /generate` → `{method, prompt, n}` → `{outputs: {persona: [str]}}`

## Evaluation metrics — current state

| Metric | Type | Reference | Weakness |
|---|---|---|---|
| Self-BLEU↓ | Diversity | Self (outputs vs. each other) | Lexical only; noise scores perfectly |
| Distinct-1/2↑ | Diversity | Self | Coarse, n-gram surface |
| SBERT-cos↓ | Diversity | Self (pairwise embeddings) | No semantic ground truth |
| Quality↑ | LLM-judge | None | GPT-4o bias toward GPT-style prose |
| Novelty↑ | LLM-judge | None | Circular: judges diversity without reference |
| Utility↑ | LLM-judge | None | Subjective rubric |
| Fidelity↑ | LLM-judge | None | No reference persona output exists |

**Core problem:** Zero external ground truth. All metrics are either self-referential (diversity) or judge-opinion (quality). High Distinct-2 ≠ meaningfully diverse arguments. High Quality ≠ objectively good counter-argument.

## Ground truth evaluation — findings & roadmap

### CMV corpus investigation (`conversations-gone-awry-cmv-corpus`)
- 6,842 conversations, 42,964 utterances
- **No post titles stored** — original "CMV: [view]" claims were stripped
- 200 utterances with delta-flair (`nΔ`) = proxy quality signal (author has changed minds before)
- 13/18 eval topic keywords found in corpus text (remote work, loneliness, aging population, standardized testing, cancel culture = missing)

### Ground truth options (priority order)

| # | Approach | Effort | Strength |
|---|---|---|---|
| 1 | Download `cmv-corpus` (full ConvoKit CMV), extract delta-winning responses, match to eval prompts by title | ~2 hrs | True reference: community-validated arguments |
| 2 | Fine-tune quality scorer on `ibm-research/argument_quality_ranking_30k` (already in pipeline) | ~1 day | Human-annotated quality, no LLM bias |
| 3 | Topic-level BERTScore vs. `conversations-gone-awry` keyword-matched comments | ~1 hr | Weak topic match only; imprecise |
| 4 | Human eval: 5 prompts × 5 raters, rate diversity + quality | ~1 week | Gold standard; required for journal |

### For journal submission
Minimum viable additions:
1. **Option 1** (cmv-corpus BERTScore) — anchors quality to real human arguments
2. **Option 4** (human eval, small) — reviewers will ask; 5 prompts × 5 raters is publishable
